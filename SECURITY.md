# Security Policy

## Supported versions
The latest `main` branch and the most recent release receive security fixes.

## Reporting a vulnerability
Please **do not** open a public issue for security problems.

Instead, use GitHub [private security advisories](https://github.com/faisukhan01/{REPO}/security/advisories/new)
to report the issue confidentially, including:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact

Patient-data safety matters: reports affecting PHI handling, RBAC, or integrations (Supabase/Airtable) are treated with highest priority.
